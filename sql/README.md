# Consultas SQL — Projeto Olist

Esta pasta reúne as consultas SQL utilizadas na análise dos dados do e-commerce Olist com Google BigQuery.

## Análises realizadas

- Evolução mensal de pedidos e receita de produtos.
- Receita de produtos por categoria.
- Ticket médio por estado.
- Percentual de pedidos atrasados por estado.
- Relação entre atraso na entrega e avaliação dos clientes.

## Ferramentas

- SQL
- Google BigQuery
- Power BI
